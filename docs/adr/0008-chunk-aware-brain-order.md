# A Chunk tries Brains that fit it first

Chunks are sized for the first Brain's budget. A fallback Brain with a smaller budget would have to drop files from its copy of the Chunk, and the Review would still read as complete. So each Chunk walks the Fallback chain with the Brains whose budget fits the whole Chunk first (in chain order); smaller Brains stay at the end as a last resort. This bends the strict chain order of ADR-0002, but only for the cases where following it would silently lose coverage. The Summary also says how many changed files were actually reviewed, and names files of a Chunk that no Brain could review separately from files trimmed to fit a budget. Rejected: re-chunking per Brain (would exceed the three-call cap) and failing the Chunk instead of trimming (a thin Review beats none).
